## 🌌 Overview

SYNAPSE AI presents a cinematic, minimalist, and monochromatic digital interface designed to reflect the technological sophistication of frontier artificial superintelligence research.

### ✨ Key Features

- **Cinematic Monochromatic Identity:** Deep obsidian blacks, charcoal surfaces, brushed metallic silver, and pure white accents with zero distracting neon or rainbow gradients.
- **3D Metallic Neural Sphere:** Procedural WebGL raymarched metallic sphere featuring studio reflections, harmonic surface wave perturbations, and dynamic mouse-tracking inertia.
- **Quantum Preloader:** System initialization animation displaying tensor memory allocation, diagnostic checks, and a live percentage counter.
- **Interactive Neural Architecture:** 6-node SVG topology diagram with animated data pulses and a real-time subsystem telemetry inspector.
- **AI Product Suite:** Interactive cards for **SYNAPSE VISION**, **SYNAPSE CORE**, **SYNAPSE VOICE**, and **SYNAPSE ANALYTICS** with bespoke generative Canvas visualizers and detailed architectural modals.
- **"Experience Intelligence" AI Emulator:** Simulated local technical intelligence terminal with 4 domain modes, one-click prompt pills, and streaming typewriter responses.
- **Acoustic Synthesizer:** Built-in Web Audio API synthesizer providing subtle cybernetic audio feedback (toggleable via the navigation bar).
- **Planetary Applications & Research Repository:** High-impact sectors and filterable whitepapers with modal abstract viewer and simulated PDF download.
- **Full Accessibility:** Complete support for `@media (prefers-reduced-motion: reduce)`, keyboard navigation, and responsive layouts across mobile, tablet, and desktop screens.

## 🚀 Quick Start

No dependencies or build steps required. Simply clone and run!

### Method 1: Direct File Opening
Double-click `index.html` to open directly in any modern browser.

### Method 2: Local HTTP Server (Node.js)
```bash
node server.js
```
Then visit `http://127.0.0.1:3000` in your web browser.
